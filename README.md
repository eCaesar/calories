# Калории

Простой дневник питания: поиск по названию, сканер штрихкодов, свои продукты. Работает в браузере телефона и ставится на экран «Домой» как приложение (PWA).

- **Справочник** обычной еды — `foods.js`.
- **Магазинные товары** — выгрузка Open Food Facts по России, Беларуси и Казахстану (`scripts/build_off_ru.py`), пересобирается раз в неделю в GitHub Actions. Если товара нет в выгрузке, приложение спрашивает Open Food Facts онлайн.
- **Свои продукты** хранятся на телефоне; товары со штрихкодом можно отправить в Open Food Facts, чтобы они нашлись у всех.

Публикация: GitHub Pages через `.github/workflows/deploy.yml`.
